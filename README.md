# elevenlabs test

Статическая коллекция 121 звука ElevenLabs. Начальная страница — `index.html` в корне. Не требует установки npm-пакетов, сборки, API-ключей или серверного кода.

## Локальный запуск

```sh
python3 scripts/serve.py --port 8080
```

Открыть http://localhost:8080. Сервер поддерживает HTTP Range для перемотки аудио. Можно открыть `index.html` напрямую: аудио, карточки и 3D-спектрограмма работают также через `file://`. Рендерер подключён обычным локальным скриптом, без ESM и ограничений CORS для модулей.

## Возможности

- Быстрое переключение между семплами; одновременно звучит только один.
- Независимая нумерация без названий: **track** начинается с `001`, **samples** — отдельно с `001`. Сейчас это `track 001` и `samples 001–120`. Поиск работает по номеру внутри открытого раздела; плеер и скачивание используют тот же номер. Сортировка номера не меняет.
- Ровно два раздела: **track** — файлы длиннее 30 секунд; **samples** — файлы до 30 секунд включительно. Сейчас это 1 трек и 120 семплов. Категория определяется автоматически по длительности.
- Три вида отображения: **Карточки**, **Плотно** и **Список**. По умолчанию включено **Плотно** — множество маленьких карточек. Вручную выбранный вид сохраняется в браузере и переключается без остановки звука.
- Shuffle возле переключателя видов перемешивает карточки открытого раздела. Повторное нажатие меняет порядок ещё раз; воспроизведение и номера сохраняются. Порядок не сбрасывается при смене вида, поиске и переходе между разделами в текущей сессии. Вернуться к исходному порядку можно через «По номеру». Кнопка случайного звука в нижнем плеере и клавиша `R` включают другой звук и сразу прокручивают страницу к его карточке.
- Звуковое полотно с адаптивной сеткой. Клик по карточке запускает звук; волна позволяет сразу выбрать нужное место. В каждом виде доступно скачивание оригинала.
- Настройки громкости, повтора и вида сохраняются в текущем браузере.
- Настоящие волны аудио с перемоткой, повтор и случайный звук. Переключение на следующий семпл — вручную.
- Клик по свободному фону нижнего плеера перематывает выбранный звук пропорционально горизонтальной позиции клика. Кнопки, громкость и полоса перемотки работают независимо. При перемотке воспроизведение продолжается, на паузе звук остаётся на паузе.
- Скачивание оригиналов без изменений под номером семпла (`001.mp3` и т. д.).
- По умолчанию выбраны **2D** и **Enable visual**. Ручной выбор режима 1D/2D/3D и включение или отключение Visual сохраняются при смене семпла и после перезагрузки страницы. Квадратная ячейка его спрайта по `artworkNumber` кодируется в частоты 180 Гц–12 кГц повторяющимися плитками вдоль всей записи. Число повторов рассчитывается по ширине панели и высоте занятой полосы частот при включении эффекта: рисунки остаются близкими к квадрату. Длительность исходного звука не меняется. Получается слышимая спектральная текстура; для читаемости рисунка исходный сигнал внутри этого диапазона приглушается, бас ниже диапазона сохраняется. Спектрограмма строится заново по полученному PCM: рисунок действительно содержится в аудио. **Disable visual** возвращает оригинал. Позиция, пауза, громкость и повтор сохраняются; при выборе другого звука его обложка обрабатывается только при включённом Visual. Отмена обработки также сохраняет выключенное состояние для следующих семплов. Во время расчёта кнопка показывает процент и позволяет отменить операцию. При смене 1D/2D/3D обработанный звук сохраняется, кнопка доступна только в 2D. Пока эффект включён, скачивание в нижнем плеере отдаёт `001-visual.wav`; скачивание из карточек всегда отдаёт исходный MP3. Для обработки нужен HTTP(S), например локальный сервер из инструкции выше; обычное воспроизведение продолжает работать через `file://`.
- Чёрный каталог с локальными IBM Plex Sans для интерфейса и IBM Plex Sans Condensed для номеров. Источники и лицензия — `assets/fonts/SOURCES.md`. В шапке нет декоративных подписей и длинных разделителей; переключатель видов состоит из трёх иконок с подсказками. Hero отсутствует.
- В карточках квадратная фотография расположена над отдельной тёмной частью с номером, длительностью, волной и скачиванием. Управление не перекрывает обложку. В плотном виде сохраняется эта структура; в списке обложка становится миниатюрой слева. Изображения имеют исходную яркость и затемняются только при наведении мыши. Текущая карточка отмечена серебристым контуром, более светлым графитовым фоном и точкой возле номера; волна и подписи тоже контрастнее. Контур не меняет размеры карточки и сохраняется на паузе. Рамок вокруг волны и отдельных кнопок play/pause нет. Клик по карточке или номеру запускает и приостанавливает звук.
- Волны рисуются в Canvas с детализацией под доступную ширину. Они находятся на тёмном фоне под обложкой, без наложенных плашек. При переключении вида волны перерисовываются без повторной загрузки аудио. Клавиатурный фокус остаётся видимым.
- У номера звука, кнопок воспроизведения и настроек нижнего плеера отдельные полупрозрачные подложки по размеру содержимого. Между группами спектрограмма открыта, общей затемняющей полосы нет. Подписи частот имеют отдельный отступ 64 px слева от контролов. Весь фон остаётся доступен для перемотки; панель адаптируется к узким экранам.
- В нижнем плеере есть переключатель **1D / 2D / 3D**, по умолчанию выбран **2D**. Режим 1D — три самостоятельные белые SVG-волны: бас 32–250 Гц, середина 250 Гц–2 кГц и высокие 2–16 кГц. У каждой собственная энергия, плотность изгибов и яркость: бас даёт крупные колебания, середина — частые изломы, высокие — мелкие резкие пики. Чувствительность настраивается по записи отдельно для каждого диапазона; порог шума не даёт тишине превращаться в волну. Атака усиливает удары сразу, без дополнительных задержек и сглаженных следов. Размах и детализация следуют измеренной энергии и распределению частот внутри диапазона. Громкость уменьшает размах всех волн, mute оставляет одну слабую линию. На паузе волны замирают, при перемотке сразу обновляются. Шкала частот скрыта. SVG обновляется до 60 кадров/с (12 при reduced motion) и адаптируется к ширине плеера. Плоская спектрограмма всего файла заполняет плеер от края до края: время слева направо, частоты снизу вверх, фиолетово-красно-жёлтая палитра и курсор текущей позиции. Карта рисуется без сглаживания, с поддержкой полного Retina-разрешения до 3×. 3D использует готовый Sonoscope Terrain: плавную спектральную поверхность с перспективой, сглаженными пиками и освещением склонов. Выбор сохраняется в браузере и при смене семплов. Переключение работает на паузе и во время проигрывания, не меняет позицию и не перезагружает аудио.
- Плавающий плеер с цветной 3D-спектрограммой за контролами. Частоты 32 Гц–16 кГц идут слева направо, последние три секунды звука уходят в глубину. Высота и цвет рельефа отражают энергию частот: тёмно-красный → оранжевый → жёлтый. Данные FFT рассчитаны из самих MP3: 256 логарифмических полос, окно Hann 4096 отсчётов, 96 кадров/с; диапазон −96…−12 дБ. Отрисовка привязана к `audio.currentTime`, поэтому работает при паузе и перемотке, без Web Audio и дополнительного подключения к динамикам. Sonoscope Terrain рисует рельеф в WebGL2; при недоступности WebGL или ошибке шейдера используется та же 3D-проекция в Canvas. Частота обновления ограничена 24 кадрами/с, при reduced motion или программной отрисовке — 12. Данные каждого файла загружаются только при выборе; все 121 спектр занимают 47,23 МБ; при выборе обычного 15-секундного семпла загружается около 0,5 МБ. Кнопок избранного и автоматического перехода нет.
- Подготовлено 200 уникальных макрофотографий: восемь WebP-атласов 5 × 5 (вместе 2,55 МБ) в `assets/art/macro-200/`. Первые 200 файлов имеют собственные ячейки без циклических повторов. Привязка обложки хранится отдельно от номера в разделе, поэтому `track 001` и `samples 001` имеют разные изображения. Изображения используются в карточках и для звукового кодирования обложки. Исходники и точные промпты встроенного image_gen сохранены рядом в `prompts.md`. Границы ячеек уточнены в `layout.json`; квадратные кропы заданы через CSS, без изменения исходных фотографий. Для повторной упаковки: `python3 scripts/prepare-artwork.py` (нужен `cwebp`). Для файлов сверх подготовленных 200 обложек используется тёмная подложка, пока не подготовлен новый набор.
- Клавиатура: `Space` — воспроизведение; `↑` / `↓` — предыдущий / следующий; `←` / `→` — ±2 секунды; `V` — вид; `/` — поиск; `R` — случайный; `L` — повтор; `M` — звук; `?` — подсказка.
- Официальный SVG-логотип ElevenLabs в шапке; справа только кнопка горячих клавиш. Фирменный символ на вкладке. Источники: `assets/brand/SOURCES.md`.
- Адаптивный интерфейс. Без CDN, аналитики и внешних запросов.

## GitHub Pages

Репозиторий: https://github.com/iamnhuman/elevenlabs. Настройка GitHub Pages:

Скрипт добавляет хеш содержимого к адресам файлов в `index.html` и к цепочке загрузки Web Worker → DSP. Это предотвращает смешение нового HTML со старыми скриптами и стилями из кэша браузера. Пути остаются относительными; npm и сборщик не нужны. `scripts/check-site.py` проверяет актуальность этих хешей.

3. Выбрать ветку с сайтом и папку **/(root)**, сохранить.

Все адреса относительные: сайт работает и в корне домена, и по адресу `username.github.io/repository/`. [Инструкция GitHub](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site).

## Добавление семплов

Положить MP3 в `samplepack/`, затем выполнить:

```sh
python3 scripts/prepare-samples.py
```

Нужны Python 3, Node.js, `ffmpeg` и `ffprobe`. Скрипт автоматически вызывает `scripts/prepare-spectra.cjs` для спектрограмм. Новые файлы добавляются после существующих; нумерация продолжается отдельно внутри каждого раздела, а привязка обложек сохраняется. Скрипт обновляет `samples.js` и `assets/audio/`: извлекает длительности и волны, создаёт копии без тяжёлых встроенных обложек. Аудиопоток копируется без перекодирования, оригиналы не меняются. 173,0 МБ оригиналов превращаются в 34,7 МБ аудио для проигрывания. Аудио загружается только по выбору пользователя; весь пак при открытии страницы не скачивается.

## Проверки

```sh
node --test tests/*.test.cjs
python3 -m unittest discover -s tests -p 'test_*.py'
python3 scripts/check-site.py --url http://localhost:8080
```

Первые две команды проверяют воспроизведение, подключение и жизненный цикл спектрограммы, историю FFT, отдельную нумерацию разделов. Третья проверяет индекс, файлы, оригиналы, безопасные относительные URL, HTTP-ответы и Range. Браузерная и визуальная проверка выполняется пользователем.

## Спектрограмма

[Sonoscope Terrain](https://mbsantiago.github.io/sonoscope/plugins/terrain/) — специализированный готовый рендерер 3D-спектрограмм. Подключены исходные шейдеры и программа библиотеки, WebGL2-рендерер, камера и цветовые карты. Исходник Terrain закреплён за ревизией `370388884aacf0bdf540ed40215dca4a2f0775d9`; движок Core — официальный npm-пакет 0.2.0. Локальная сборка и лицензия MIT находятся в `assets/vendor/sonoscope/`, происхождение — в `NOTICE.md` и `provenance.json`. Для открытия сайта сборка и внешние запросы не нужны.

`player-spectrum.js` загружает измеренные спектры из `assets/spectrum/` и синхронизирует их с позицией аудио. `spectrogram-view.js` переключает сохранённые SVG/Canvas трёх режимов: `spectrogram-1d.js` рисует три независимые SVG-волны по энергии частотных диапазонов, `spectrogram-3d.js` адаптирует измеренные данные к Sonoscope Terrain, `spectrogram-2d.js` — плоскую карту. В 2D цветовая карта рассчитывается один раз для файла и громкости, а при воспроизведении перемещается курсор. Данные рассчитаны из PCM реального файла. В режимах 2D и 3D показан измеренный спектр; 1D — стилизованные волны по энергии отдельных диапазонов, с движением от часов аудио. При необходимости пересчитать их отдельно: `node scripts/prepare-spectra.cjs`. Внешних запросов во время воспроизведения нет.

`spectral-image.js` декодирует выбранный MP3 через OfflineAudioContext с частотой 32 кГц и вырезает его обложку из атласа. `spectral-image-worker.js` выполняет синтез и повторный анализ в Web Worker. `spectral-image-dsp.js` содержит собственную реализацию FFT/IFFT: окно Hann 2048–8192 в зависимости от длительности одной плитки, шаг 1/8 окна, плавное наложение окон и ограничение пиков до 0,96. Фотография переводится в яркость с нормализацией контраста; горизонталь циклически повторяется по времени, вертикаль соответствует логарифму частоты. На коротких плитках уменьшается окно синтеза и повторного FFT-анализа, чтобы сохранить горизонтальные детали. Цвета исходной фотографии не кодируются: на экране используется цветовая шкала спектрограммы. Измеренный спектр WAV — 256 полос, 48 кадров/с, −96…−12 дБ. Воспроизведение и экспорт используют один и тот же 16-битный PCM; звук проигрывается через существующий `<audio>`. Результат хранится только для текущего трека, устаревшие задачи прерываются, Blob URL освобождается при смене трека. Исходные файлы не перезаписываются.

Открытые примеры подхода: [img-encode (JavaScript, MIT)](https://github.com/alexadam/img-encode), [Image to Sound — описание inverse STFT](https://geetkhatri.github.io/projects/img2sound/). Сторонний код из этих проектов не включён; реализация здесь учитывает спрайты, логарифмическую шкалу, стерео и существующий плеер. Регрессионные тесты проверяют, что рисунок восстанавливается из PCM, частоты и время не перевёрнуты, оригинальный стереобас сохраняется, переключение и отмена не подменяют звук другого трека.


Дизайн выполнен с применением [frontend-design от Anthropic](https://github.com/anthropics/skills/tree/main/skills/frontend-design). Интерфейс и Canvas-волны написаны для этого проекта.
